بناء ملف APK للعبة Desert Strike

المتطلبات (على الكمبيوتر):
1) Node.js 18 أو أحدث
2) JDK 17
3) Android Studio (يثبّت Android SDK)، وتأكد أن المتغير ANDROID_HOME يشير إلى مجلد الـ SDK
4) اتصال بالإنترنت

الخطوات:
  cd desert-strike-apk
  node build-apk.js

الناتج:
  android/app/build/outputs/apk/debug/app-debug.apk

انقل الملف إلى هاتفك وثبّته (فعّل "التثبيت من مصادر غير معروفة").
